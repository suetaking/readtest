# 단어장 — Словарь слов EN/RU/KR/UZ

Тренажёр слов с карточками, тестом и списком, поддержка четырёх языков (английский, русский, корейский, узбекский).

## Возможности

- 🃏 Флеш-карточки с переворотом и озвучкой (Web Speech API)
- 🎯 Тест с автоподбором «слабых» слов
- 📚 Список всех слов с поиском, фильтром по уровню (A1–B2) и статусу
- 📊 Дашборд прогресса
- 💾 Экспорт / импорт прогресса в JSON (хранится локально, в `localStorage`/памяти вкладки)

## Структура проекта

```
.
├── index.html   — разметка страницы
├── style.css    — стили
└── script.js    — логика приложения и база слов
```

## Запуск

Просто откройте `index.html` в браузере — сборка не требуется.

### GitHub Pages

1. Запушьте репозиторий на GitHub.
2. В настройках репозитория откройте **Settings → Pages**.
3. В качестве источника выберите ветку `main` (или `master`) и папку `/root`.
4. Сайт появится по адресу `https://<username>.github.io/<repo>/`.
